# Restaurant Management System

This project is a database-based Restaurant Management System developed using MySQL.

## 📌 Features
- Employee management
- Customer tracking
- Order processing
- Payment handling
- Inventory management
- Reservation system

## 🛠 Technologies Used
- MySQL
- MySQL Workbench

## 📊 Database Concepts Used
- ER Diagram
- Normalization (up to 3NF)
- Joins
- Views
- Triggers
- Stored Procedures
- Indexes

## ▶️ How to Run
1. Open MySQL Workbench
2. Open `project.sql`
3. Run the script
4. Use `USE RestaurantDB;`
